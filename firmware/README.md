## 1. Directory Structure
```
firmware/
├── README.md                      <-- This document
├── mcxn236/                       <-- NXP FRDM-MCXN236 Edge Brain (C11)
│   ├── CMakeLists.txt             <-- MCUXpresso / Zephyr / Host build
│   ├── Makefile                   <-- Host compilation & test target
│   ├── include/
│   │   ├── resilink_config.h      <-- System constants, timings, protocols
│   │   ├── resilink_types.h       <-- Core structures, headers, payloads
│   │   ├── resilink_crypto.h      <-- AES-256-GCM, ECDH, ECDSA, HKDF
│   │   ├── vitals_sensor.h        <-- MAX30102 + Seeded multi-scenario simulator
│   │   ├── tft_display.h          <-- 2.8" SPI TFT renderer + sparkline
│   │   ├── local_uart_stream.h    <-- 1 Hz localhost unencrypted JSON stream
│   │   ├── risk_engine.h          <-- TinyML INT8 + NEWS2 fallback
│   │   ├── delta_snapshot.h       <-- Keyframe + delta compression & flash ring buffer
│   │   ├── alert_manager.h        <-- Buzzer patterns, ACK button, failsafe relay
│   │   ├── emergency_trigger.h    <-- GPS NMEA parser, consent check, signed trigger
│   │   ├── route_manager.h        <-- Link AI, stability dwell timer, SOS flood
│   │   ├── risk_model_data.h      <-- Autogenerated INT8 risk model weights
│   │   └── link_model_data.h      <-- Autogenerated INT8 link-state model weights
│   └── src/
│       ├── main.c                 <-- 1 Hz application loop
│       ├── resilink_crypto.c      <-- Crypto implementation
│       ├── vitals_sensor.c        <-- Vitals & simulator implementation
│       ├── tft_display.c          <-- Display implementation
│       ├── local_uart_stream.c    <-- Localhost UART formatter
│       ├── risk_engine.c          <-- TinyML & NEWS2 engine
│       ├── delta_snapshot.c       <-- Snapshot engine implementation
│       ├── alert_manager.c        <-- Alert & relay implementation
│       ├── emergency_trigger.c    <-- Emergency trigger implementation
│       └── route_manager.c        <-- Route arbitration implementation
└── esp32/                         <-- ESP32 Radio Bridge (ESP-IDF)
    ├── CMakeLists.txt
    ├── sdkconfig.defaults
    ├── README.md
    └── main/
        ├── main.c
        ├── uart_bridge.h / .c     <-- 460800 baud CRC-16 UART bridge
        ├── priority_queue.h / .c  <-- 2-bit priority queue (P0 > P1 > P2)
        ├── wifi_manager.h / .c    <-- Dual-AP client & auto-failover
        └── oled_display.h / .c    <-- SSD1306 OLED status display
```

---

## 2. Quickstart & Host Verification
To compile and execute the MCXN236 edge brain firmware on host:
```bash
cd firmware/mcxn236
make clean && make
./resilink_mcxn236
```
